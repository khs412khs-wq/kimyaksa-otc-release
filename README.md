# 김약사-OTC 내려받기

일반약 바코드를 찍으면 복약지도 라벨이 나오는 약국 카운터용 프로그램입니다.
인터넷 없이 동작합니다.

## 내려받기

**[최신판 내려받기](../../releases/latest)** — `kimyaksa-otc-setup.exe`

## 설치

1. 내려받은 `kimyaksa-otc-setup.exe` 를 두 번 누릅니다.
2. **파란 경고창이 뜹니다** — `추가 정보` → `실행` 을 누르세요.
   프로그램 서명을 사지 않아서 뜨는 창입니다. 바이러스가 아닙니다.
3. 설치할 곳을 묻지 않습니다. 관리자 권한도 필요 없습니다.
4. 바탕화면에 바로가기가 생깁니다.

## 필요한 것

- 윈도우 10 (1809) 이상, 64비트
- 바코드 스캐너 (키보드처럼 꽂으면 잡힙니다)
- 라벨 프린터 — 드라이버는 미리 깔아 두세요.
  Brother QL-800, BIXOLON SLP-DX220 에서 써 봤습니다.

프린터가 없어도 앱은 뜹니다. 인쇄만 안 됩니다.

## 알아 두실 것

- 약 정보는 프로그램 안에 들어 있습니다. 설치하면 바로 찍어 볼 수 있습니다.
  식약처·심평원 공개 자료로 만들었습니다.
- 우리 약국 취급품목과 고쳐 쓴 복약지도는 그 PC 안에만 남습니다.
  새 판으로 바꿔도 그대로 있습니다.
- 복약지도 문구는 참고용입니다. **최종 판단은 약사가 합니다.**

## 소스코드

소스는 따로 비공개로 두고 있습니다. 이곳은 받아 쓰기 위한 자리입니다.
